# tmux 설정 재사용 요구사항

## Before: 원문

> tmux에서 내가 원하는 세팅이 있어. 매번 새로운 pc에서 tmux 설정할 때마다 계속 설정 만지기 귀찮으니까, 내 github repo 읽고 그 세팅 그대로 해줄 수 있도록 하면 좋겠어. 내가 원하는 조건은 tmux에서 마우스 클릭으로 pane간 이동 지원. 마우스 휠로 스크롤 지원 등이야. 이거 repo에 올려줘.

## After: 확정 요구사항

목표: 새 PC에서 공개 GitHub 저장소를 읽고 한 번의 설치 스크립트 실행으로 같은 tmux 마우스 설정을 적용한다.

| 질문 | 사용자 결정 |
|---|---|
| 저장소 | 별도 tmux 설정 전용 저장소 생성 |
| 지원 환경·적용 방식 | Ubuntu/Linux·macOS·WSL, 설치 스크립트 한 번 실행 |
| 설정 범위 | 현재 PC의 마우스 설정 그대로 (`set -g mouse on`) |
| 공개 범위 | 공개, 새 PC나 AI가 로그인 없이 읽을 수 있음 |
| 요구사항 저장 | README와 함께 requirements/ 문서 저장 |

범위: 설정 파일, 기존 설정을 백업하는 반복 실행 가능한 설치 스크립트,
운영체제별 준비 명령, AI에게 전달할 설치 요청 예시를 제공한다.

제약: prefix·테마·복사 동작·기록 크기를 추가 변경하지 않는다.
Windows 네이티브/MSYS2 설치는 이번 범위에 포함하지 않는다.

성공 기준:

1. `parktune/tmux-config` 공개 저장소에서 파일을 읽을 수 있다.
2. Git과 tmux 설치 후 `sh install.sh`로 설정을 적용한다.
3. 클릭으로 pane 선택, 휠 스크롤, 드래그 크기 조절이 활성화된다.
4. 기존 설정은 백업하고 같은 설정을 재설치하면 불필요한 백업이 생기지 않는다.
5. tmux 설정 로딩과 `mouse on` 값을 격리된 서버에서 확인한다.

## 추가 요구사항: 설치 후 정리

- `bootstrap.sh`로 설치하면 임시 디렉터리에 Git 저장소를 받고 설정 적용 후 삭제한다.
- 실패·중단 시에도 이번 실행에서 만든 임시 디렉터리를 정리한다.
- tmux가 이미 설치되어 있으면 재설치·업데이트하지 않고 설정만 바꾼다.
- tmux나 Git이 없으면 지원하는 패키지 관리자로 필요한 패키지만 설치한다.
- 설정 파일과 백업은 유지한다. 수동 관리용 `install.sh`도 제공한다.
